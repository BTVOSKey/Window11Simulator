# Window11Simulator
Dự án này là trình giả lập hệ điều hành Windows, cho phép trải nghiệm giao diện và sử dụng các ứng dụng Windows ngay trên thiết bị Android. Tối ưu hóa cho màn hình cảm ứng, hoạt động mượt mà trên nhiều dòng máy, giúp truy cập môi trường Windows mọi lúc mọi nơi mà không cần máy tính cá nhân. Dự án sẽ tiếp tục được cải thiện hiệu suất
